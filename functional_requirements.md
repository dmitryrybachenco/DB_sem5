# Функциональные требования

**Проект:** Система интернет-провайдер

## Обязательные требования

### 1. Авторизация/аутентификация пользователя
- Вход в систему по email/логину и паролю.
- Хеширование паролей.
- Восстановление пароля через email.
- Сессионная аутентификация.

### 2. Управление пользователями
- Создание нового пользователя.
- Просмотр списка пользователей с фильтрацией и поиском.
- Редактирование данных пользователя.
- Деактивация/удаление пользователя.
- Блокировка учётной записи.

### 3. Система ролей
- Роли: `admin`, `manager`, `engineer`, `support`, `client`.
- Назначение ролей пользователям.
- Разграничение доступа к функционалу по ролям.
- Возможность наличия нескольких ролей у одного пользователя.

### 4. Журналирование действий пользователя
- Запись всех значимых действий (вход, создание/изменение/удаление).
- Фиксация: кто, что, когда, с какого IP.
- Просмотр журнала администратором.
- Хранение истории изменений.

## Дополнительные требования

### 5. Управление абонентами
- Ведение карточки абонента.
- Привязка абонента к договору.

### 6. Управление тарифными планами
- Создание/редактирование тарифов.
- Архивация устаревших тарифов.
- Смена тарифа абонентом.

### 7. Управление услугами
- Каталог услуг.
- Подключение/отключение услуг абоненту.

### 8. Биллинг и платежи
- Начисление абонентской платы.
- Регистрация платежей.
- Формирование счетов.

### 9. Управление адресами подключения
- Справочник городов, улиц, домов.
- Привязка абонента к адресу.

### 10. Отчётность
- Отчёт по платежам за период.
- Отчёт по активным абонентам.
- Отчёт по подключённым услугам.
